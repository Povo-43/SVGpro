# 未実装機能と既知の制約

## 描画（レンダリング）

- **`<style>` 内のCSS**: 解析せずテキストとして保持のみ。class属性によるスタイル適用は未対応（個別属性・style属性は対応）
- **`<filter>` / SMILアニメーション**: 保持のみで描画しない
- **`<mask>` の描画**: 輝度マスクを輝度近似（白=表示/黒=隠す）でDST_IN合成。部分的な輝度グラデーションマスクは近似になる
- **`<pattern>` の描画**: userSpaceOnUse + patternTransform（scale/rotate/translate）の近似。contentUnits=objectBoundingBox は保持のみ
- **テキストのtspan**: 子tspanは無視され、textContentを1行で描画（保存は保持される）
- **テキストフォント**: sans-serif / serif / monospace の近似。font-family属性は保存時に保持されるため、対応ビューアでは正しく表示される
- **テキストのtextPath描画**: 文字をフラット化したパス上に接線方向へ配置する近似。外部ビューアではtextPath構造そのまま描画される
- **外部画像 / 外部参照**: セキュリティ方針により読み込まない（data URIの埋め込み画像のみ表示）
- **group opacity**: fill-opacity/stroke-opacity は要素opacityのみ対応

## パス編集

- **アーク (A) を含むパスのノード編集**: ノードモデルへの取り込み時にcubicへ展開される（保存時もC表記。表示は同一）
- **ペンツールでの既存パス端点からの継続**: 未実装（端点接続・ノード追加で代用）
- **ハンドルの数値入力**: ダイアログで長さ+角度を指定（選択中の1ノード。ドラッグ併用）
- **ブーリアン/オフセット/ストローク化は曲線をフラット化してから演算**: 結果はポリライン近似（許容誤差はズーム適応）。fill-ruleはevenodd出力（巻き方向はnonzero互換に統一）
- **オフセットの結合スタイル**: ラウンド/マイター対応（ベベルはUI未整理）
- **ノード削減**: 閉パスの端点保護・許容誤差はズーム適応（結果はポリライン近似を含む）

## 基本編集

- **傾斜（skew）のハンドル**: 未実装（数値変形ダイアログで skewX/skewY を指定）
- **回転中心のドラッグ指定**: 未実装（数値変形はbbox中心、回転ハンドルはbbox中心基準。Shiftで15°スナップ）
- **複数親にまたがる選択のグループ化**: 同一親内のみ対応
- **useで参照されるシンボル定義の直接編集**: インスタンス解除→編集のフローで代用

## UI / 操作

- **文字揃え（垂直）・文字間隔・行間隔のUI**: 未実装（属性は保持）
- **複数ページ / アートボード**: 非対応
- **SVGZ（gzip）**: 非対応
- **ショートカットのカスタマイズ / 最近使ったツール / 名前検索**: 未実装
- **スウォッチの保存/読み込み・最近使った色**: 未実装
- **ガイドの角度付きガイド**: 水平/垂直のみ

## 永続化

- **オートセーブ**: 30秒間隔でキャッシュディレクトリへバックアップ（未保存時のみ）。起動時に復元確認。手動保存で消去
- **完全なセッション復元（Undo履歴・選択状態）**: バックアップはドキュメントのみ

## 既知の動作上の注意

- 2本指ジェスチャはツール操作より常に優先。作図中に2本目の指を置くと作図はキャンセルされパン/ズームへ遷移する（意図的な仕様）
- 変換ハンドルによるscale/rotateは `transform` 層に累積する（元の幾何は保持=非破壊）
- 筆圧フリーハンドは幅可変の塗りポリゴンを生成する（ストローク属性ではなく輪郭）。筆圧非対応端末では一定幅
- ブーリアン結果の穴は evenodd + 巻き方向統一で保持されるため、nonzeroに切り替えても穴は維持される
- クリップ/マスク定義はdefsに残る（解除しても定義は消えない=再適用可能。不要な定義は手動削除が必要）
