# 未実装機能と既知の制約

## 描画（レンダリング）

- **`<style>` 内のCSS**: 解析せずテキストとして保持のみ。class属性によるスタイル適用は未対応（個別属性・style属性は対応）
- **`<mask>`**: 保持のみで描画しない（`<clipPath>` はcanvasクリップとして簡易対応…v1.0ではクリップ適用も未実装。保持のみ）
- **`<filter>` / SMILアニメーション**: 保持のみで描画しない
- **テキストのtspan**: 子tspanは無視され、textContentを1行で描画（保存は保持される）
- **テキストフォント**: sans-serif / serif / monospace の近似。font-family属性は保存時に保持されるため、対応ビューアでは正しく表示される
- **group opacity / fill-opacity / stroke-opacity**: fill-opacity等の個別不透明度は要素opacityのみ対応
- **パターン塗り / `<marker>`**: 未対応（保持のみ）
- **外部画像 / 外部参照**: セキュリティ方針により読み込まない（data URIの埋め込み画像のみ表示）
- **use**: 同ドキュメント内参照のみ（1段階の形状参照）

## パス編集

- **アーク (A) を含むパスのノード編集**: ノードモデルへの取り込み時にcubicへ展開される（保存時もC表記になる。表示は同一）
- **ペンツールでの既存パス端点からの継続**: 未実装（既存パスへの追加はノードツール＋ダブルタップ挿入で代用）
- **セグメントの切断（scissors）**: 未実装
- **ハンドルの数値入力**: 未実装（ドラッグのみ）
- **ブーリアン/オフセット/単純化は曲線をフラット化してから演算**: 結果はポリライン近似（許容誤差はズーム適応）。fill-ruleはevenodd出力
- **オフセットの結合スタイル**: round固定（miter/bevel選択は未対応）

## 基本編集

- **傾斜（skew）のハンドル/数値UI**: 未実装（transform属性は手動編集可能）
- **回転の数値入力**: 未実装（ハンドルドラッグのみ。Shiftで15°スナップ）
- **複数親にまたがる選択のグループ化**: 同一親内のみ対応

## UI / 操作

- **ルーラー / ガイド線**: 未実装
- **文字揃え・文字間隔・行間隔のUI**: 未実装（属性は保持）
- **グラデーションエディタ**: ストップの追加/削除・ハンドルのドラッグは未対応（生成＝2ストップ）
- **複数ページ / アートボード**: 非対応
- **SVGZ（gzip）**: 非対応

## 永続化

- **プロセス死からの自動復元**: 未実装（回転・バックグラウンド遷移はViewModelで保持）。保存していない編集はプロセス強制終了で失われる
- **オートセーブ**: 未実装（未保存マーク＋戻るボタンで警告）

## 既知の動作上の注意

- 2本指ジェスチャはツール操作より常に優先。作図中に2本目の指を置くと作図はキャンセルされパン/ズームへ遷移する（意図的な仕様）
- 変換ハンドルによるscale/rotateは `transform` 属性に累積する（Illustrator式のジオメトリ破壊はしない）
- 大きなドキュメント（数千要素）ではTrace再構築が毎フレーム発生するため、編集操作が重くなる可能性がある
- 楕円のrx/ry等のプリミティブ属性を直接編集するUIは未実装（選択→パス変換またはノード編集で代用）
